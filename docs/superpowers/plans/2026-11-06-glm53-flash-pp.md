- FP32 gates lose information when copied to BF16 receive buffers: exact mixed-dtype copy/slice regression (Task 1).
- SP shard padding / partial tokens get mixed by PP's TP optimization: layout round-trip with non-divisible token counts plus real distributed tests (Tasks 1–2).
- Nonlocal FP8 scale/weight pairs enter pending dequantization: real model loader regression and early PPMissing filter (Task 2).
- MTP embedding priority depends on checkpoint ordering: target/draft embedding ordering, missing-embedding and PP1 regressions (Task 3).
- A boundary falls on another hybrid layer type or the last layer: exhaustive four-stage CPU math boundaries and real LLM PP1/PP4 regression (Tasks 1, 4).
